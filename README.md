# Живая карта — AR-прототип для MAX

Мини-приложение демонстрирует распознавание **самой иллюстрации**, а не QR-кода: после обнаружения маркера поверх него появляется анимация.

## Запуск

```bash
npm run dev
```

Для теста откройте `/markers/forest-guardian.svg` на втором экране или распечатайте его, а затем нажмите «Открыть камеру».

## Что уже сделано

- адаптивный интерфейс Mini App;
- запрос камеры через MAX Bridge при запуске внутри MAX;
- браузерный AR-движок с image tracking;
- локальная подготовка распознавания для встроенного или загружаемого маркера;
- анимация, привязанная к найденной иллюстрации;
- макет админ-раздела для следующего этапа.

## Что потребуется для интеграции с MAX

1. Верифицированный профиль на платформе MAX для партнёров и созданный бот.
2. HTTPS-домен с опубликованной сборкой.
3. Токен бота и URL webhook для серверной части.
4. Список MAX ID администраторов, которым будет доступна команда `/admin`.

Камера в Mini Apps MAX по текущей документации доступна на Android и в веб-клиенте. Для остальных клиентов следует сохранить экранный сценарий без камеры.
