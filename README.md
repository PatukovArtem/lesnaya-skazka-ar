# Лесная сказка — AR-сайт

Обычный сайт с распознаванием **самих иллюстраций**, а не QR-кодов: после обнаружения маркера поверх него появляется анимация.

## Запуск

```bash
npm run dev
```

Для теста откройте или распечатайте одну из иллюстраций из `public/markers/stories/`, затем нажмите «Открыть камеру».

## Что уже сделано

- адаптивный веб-интерфейс;
- стандартный запрос к камере браузером только при запуске сканера;
- браузерный AR-движок с image tracking;
- распознавание всех добавленных иллюстраций;
- анимация, привязанная к найденной иллюстрации.

Для работы камеры сайт должен быть открыт по HTTPS (или на `localhost` во время разработки).
