# Размещение «Лесной сказки» в Selectel

Сайт является статическим: он не требует виртуального сервера, базы данных или бэкенда. Для публикации используйте S3 Selectel как хранилище файлов и CDN Selectel для HTTPS и быстрой доставки видео.

## 1. Подготовить выпуск

В корне проекта выполните:

```bash
npm install
npm run package:selectel
```

Команда создаст папку `release/selectel/`. В ней должны быть:

- `index.html`;
- `assets/` — собранные JavaScript и CSS;
- `media/stories/` — видео персонажей;
- `markers/` — изображения-маркеры и файл `story-targets.mind`.

Не загружайте в хранилище исходные папки `src/`, `node_modules/` и саму папку `release/`. В S3 нужно загрузить **содержимое** `release/selectel/`, чтобы `index.html` находился в корне бакета.

## 2. Настроить S3

1. В панели Selectel создайте проект, затем S3-бакет, например `lesnaya-skazka`.
2. Сделайте бакет публичным для чтения — посетителям должны быть доступны HTML, JavaScript, изображения и видео.
3. Загрузите в корень бакета содержимое `release/selectel/`.
4. Откройте **S3 → Бакеты → ваш бакет → Веб-сайт** и включите режим **Хостинг**.
5. В качестве главной страницы укажите `index.html`.

Проверьте типы файлов после загрузки:

| Файлы | Content-Type |
| --- | --- |
| `.html` | `text/html; charset=utf-8` |
| `.js` | `text/javascript` |
| `.css` | `text/css` |
| `.mp4` | `video/mp4` |
| `.jpg`, `.png` | `image/jpeg`, `image/png` |
| `.mind` | `application/octet-stream` |

## 3. Подключить CDN и HTTPS

Камера сайта открывается только по HTTPS, поэтому не публикуйте финальную версию только на техническом HTTP-адресе S3.

1. В Selectel откройте **Продукты → CDN → Создать ресурс**.
2. Выберите оптимизацию **«Статика»** и укажите созданный S3-бакет как источник.
3. После создания Selectel выдаст адрес `*.selcdn.net` и автоматически выпустит для него HTTPS-сертификат. По этому адресу можно провести первый публичный тест.
4. Для постоянного адреса добавьте персональный поддомен, например `ar.леснаясказка.рф` или `www.lesnaya-skazka.ru`. В DNS домена создайте CNAME на адрес CDN, выданный Selectel.
5. Выпустите сертификат Let's Encrypt в настройках CDN и включите перенаправление с HTTP на HTTPS.

Для CDN Selectel персональным доменом служит поддомен: для корневого `lesnaya-skazka.ru` используйте `www.lesnaya-skazka.ru` или `ar.lesnaya-skazka.ru`. Корневой домен можно перенаправить на этот адрес у регистратора.

## 4. Проверить до запуска

1. Откройте сайт на смартфоне по HTTPS.
2. Нажмите «Открыть камеру» и разрешите браузеру доступ к камере.
3. Наведите камеру на несколько иллюстраций из `markers/stories/`.
4. Убедитесь, что подгружаются и воспроизводятся соответствующие видео.

## Обновление сайта

После изменений снова выполните `npm run package:selectel`, замените содержимое бакета файлами из `release/selectel/` и очистите кэш CDN. Для `index.html` используйте короткое кэширование, а для изображений и видео — длительное: так посетители быстрее получат обновлённую версию страницы, не скачивая тяжёлые ролики каждый раз.
